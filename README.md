# QG NVB — SITE

Este pacote é o **site/QG da Nytheris Vampyre Bloodline** separado do bot Tenchiko.

## Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Port: `10000`

O site usa o Discord para carregar informações do servidor, então `DISCORD_TOKEN`, `CLIENT_ID` e `GUILD_ID` continuam necessários no Environment.

Os comandos/slash commands do NVB não são registrados por este serviço. O bot separado fica responsável pelos comandos.
